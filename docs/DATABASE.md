# 데이터베이스

기존 `judge_store` JSONB의 사용자·문제·제출·대회 기록을 재사용합니다. 새로운 분석 시스템은 `solvex_reviews`와 `solvex_controls`를 부팅 때 추가합니다. 기존 테이블을 삭제하거나 데이터 형식을 변환하지 않습니다. 예전 시작 코드에서 오래된 문제를 삭제하거나 자동으로 AC 기록을 추가하는 동작을 제거했습니다.

분석 행은 계정 ID, 유형, 시각, HMAC 지문, 처리 결과를 보관합니다. 성공 행에는 원본 사진을 제외한 입력과 구조화된 보고서가 저장됩니다. 사용자가 기록을 삭제하면 보고서와 텍스트를 제거하고 쿼터 계산용 메타데이터는 유지합니다. 기존 회원 삭제와 분석 데이터 일괄 삭제의 연동, 장기 보존 기간 정책은 공개 AI 전 확정해야 합니다.

로컬 개발에만 JSON 파일을 사용합니다. 테스트의 `LOCAL_DB_FILE`은 별도 임시 파일입니다. 운영 DB는 배포 전 공급자 도구로 스냅샷 또는 내보내기를 확보하세요. 롤백에서는 기존 DB 연결을 유지하고 기존 프로그램을 먼저 복원합니다. 새 분석 테이블을 수동으로 삭제할 필요가 없습니다.
