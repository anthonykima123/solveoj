# 보안

- 실제 분석 요청은 로그인, 비공개 검토 계정 목록, 세션 CSRF 토큰, 전송 동의를 모두 확인합니다.
- 계정·전체·분당·동시 요청 및 중복 방어는 Postgres에 기록됩니다. 외부 쿼터 초과 후 당일 추가 호출을 막습니다.
- 결과 조회와 삭제는 소유자 조건이 포함된 SQL을 사용합니다. EJS 본문은 이스케이프합니다.
- 기존 제출 코드 열람 제한을 유지하고 비공개 문제의 통계를 가립니다. 오류 메시지는 작성자에게만 표시합니다.
- 공개 폼의 교차 출처 제출을 제한합니다. 로그인 시 세션을 재발급하고 운영 환경의 보안 쿠키와 비밀값을 강제합니다.
- 웹 서버의 실제 코드 실행 및 자유 컴파일 진입점을 비활성화합니다.
- 운영 로그에는 요청 번호와 실패 유형만 기록합니다. 파일 이름이나 키, 분석 내용은 남기지 않습니다.
- 배포 전에 기존 인증·세션의 저장 정책, 취약점 점검, 정책 문서 및 계정 삭제 동작을 검토해야 합니다.
