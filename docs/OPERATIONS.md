# 운영

슈퍼 관리자 계정은 `/admin/solvex`에서 한국 시간 기준 요청·성공·실패 수를 보고 일시 중지 또는 재개할 수 있습니다. 기존 사용자와 문제 관리는 `/admin`에 있습니다. 신규 DB에는 기본 관리자 비밀번호를 생성하지 않습니다.

기본 한도는 계정당 하루 3회, 전체 하루 20회, 분당 4회, 동시 2회, 입력 12,000자, 사진 1MB입니다. 외부 API가 429를 반환하면 마지막 제한 요청의 시작 시각을 기준으로 1분 동안 새 호출을 중지합니다. 일일 요청 한도는 한국 시간 자정에 초기화됩니다. 분석이 실패해도 허위 결과를 반환하지 않습니다.

자동 테스트를 운영 브랜치의 필수 검사로 설정하려면 GitHub Rulesets에서 SOLVEX checks의 `verify` 작업을 요구하도록 설정하세요.
